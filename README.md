# Biografía Personal

Sitio web de biografía personal con información personal y horario de clases.

## Características

- Biografía personal con imagen
- Horario de clases en formato tabla
- Navegación interna
- Diseño responsivo

## Tecnologías utilizadas

- HTML5
- CSS3

## Cómo usar

Simplemente abre el archivo `index.html` en tu navegador web.
